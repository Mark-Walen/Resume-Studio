# 测试计划

## 1. 自动检查

- `npm run lint`：TypeScript 全量类型检查。
- `npm run build`：生产构建与动态分包。
- `git diff --check`：空白和补丁完整性。

## 2. 身份与账户

- 邮箱注册、验证、登录、退出、忘记密码、修改密码。
- Google 登录选择账户。
- 修改昵称和 HTTPS 头像。
- 最近账户列表不包含密码或 token；切换后显示预填邮箱登录页。
- A 用户不能读取 B 用户的工作区、还原点、附件或发布管理接口。

## 3. 同步与恢复

- 首次登录分别覆盖：云端已有、本地已有、全新账户。
- 修改单一数据域后 PATCH 请求只包含该域。
- 全量更新后重新登录数据一致。
- 创建还原点、继续修改、回滚，检查所有数据域和本地缓存恢复。
- 模拟网络失败：提示可关闭、图标为断云、本地编辑仍保存、重试成功后恢复正常。

## 4. 简历与翻译

- 多份简历 CRUD、导入替换/合并不产生重复副本。
- 自定义模块排序时不出现删除按钮。
- PDF、Word、Markdown 与预览顺序/显隐一致。
- 翻译产生新 ID，不改源简历；邮箱、电话、URL、日期、数字不被改写。
- 忠实直译和当地风格模式均不新增事实。
- 英语/西语、德语/法语、东亚语言分别匹配预期模板。

## 5. 知识与 Markdown

- 粘贴含 `&#x20;`、转义列表符号、转义围栏和行尾反斜杠的 Markdown。
- 结果包含标题、无序列表和代码块，而不是一个纯文本段落。
- 修改专栏名称/描述；发布、撤回、分享。
- 阅读选区可高亮、生成闪卡和保存笔记；社区发布不泄露这些私人标注。

## 6. 性能

- 游客首屏不加载 App 工作区。
- 非当前页不加载面试、知识库、PDF 和块编辑器包。
- 对大简历和大专栏检查交互延迟、导出内存与移动端滚动。
