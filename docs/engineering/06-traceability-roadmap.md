# 需求追踪与路线图

## 已交付

- 从 Agent/ChatGPT 历史抽取工作证据、重建时间线并生成嵌入式简历。
- 多模板简历、模块排序/显隐、自定义富文本、头像、求职意向、证书时间。
- PDF/Word/Markdown/Agent 格式导出及 PDF 分页修复。
- 多 AI Provider、动态模型列表、自定义兼容协议、思考强度和加密 Key。
- Identity Platform、Cloud Run、Cloud SQL、Cloud Storage 与跨设备工作区。
- 多份简历、职位浏览器辅助导入、公司背调、职位沟通、面试复盘。
- 所见即所得知识编辑器、Markdown 粘贴转换、专栏元数据、阅读标注、发布与分享。
- 演示数据清除、XSS/危险 URL 防护、按需加载、统一 footer 与账户设置。
- 断云提示可关闭、失败图标、多账户切换、增量/全量同步和还原点。
- 简历忠实翻译、目标地区风格本地化及语言模板匹配。

## 下一阶段
