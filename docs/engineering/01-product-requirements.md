# 产品需求说明（PRD）

## 1. 产品目标

Resume Pilot 是面向求职全过程的个人职业工作台。系统把工作证据、简历、多公司投递、面试、知识专栏、闪卡和求职手记连成一条可追溯链路，并允许用户选择自己的模型服务。

## 2. 用户边界

- 游客：仅能访问公开首页、产品说明及登录/注册入口。
- 登录用户：只能访问自己的简历、投递、面试、附件、笔记、模型配置元数据和云端工作区。
- 社区读者：登录后可试读或订阅已发布专栏。
- 管理员：通过配置的管理员邮箱读取问题反馈；本阶段不提供“增加用户”功能。

## 3. 核心功能

### 3.1 简历工坊

- 保存和切换多份简历，支持复制、重命名、删除、导入和共享。
- 导入文本、Markdown、PDF；导出 PDF、Word、Markdown 和 Agent 友好格式。
- 模块显隐与排序分离；基本信息和个人总结是必选模块。
- 自定义模块支持富文本，排序模式不显示删除按钮。
- 预览与导出遵循同一模块顺序、时间排序和模板。
- 支持头像、求职意向、期望薪资、证书可选时间以及 5:7 证件照展示。
- 支持简历语言元数据、忠实直译、目标地区风格本地化；翻译生成独立副本，避免覆盖原文。
- 东亚语言优先现代轻简模板；英语、西班牙语等优先 ATS 友好的密集模板；德语、法语优先经典模板。

### 3.2 求职与面试

- 投递看板、面试日程、公司背调和多公司定向精修。
- 浏览器辅助导入招聘网页，正文清洗必须去除导航、推荐职位、页脚和安全提示等噪声。
- 导入的职位标题、公司、薪资、地点、JD、公司介绍和来源链接必须同步到看板详情。
- 职位沟通助手应解释问题意图、给出回答结构、口语化示例与追问准备。
- 面试录音/视频存 Cloud Storage，结构化元数据存工作区。

### 3.3 知识与证据

- 个人专栏可编辑名称和描述，可发布、撤回、分享。
- 社区专栏与个人专栏分区；个人订阅副本保存自己的进度、标注和笔记。
- 阅读模式支持选中文字、高亮、制作闪卡和阅读笔记。
- 编辑器是所见即所得块编辑器；Markdown 粘贴自动转换标题、列表、引用、代码块等。
- 求职手记可沉淀工作证据并转为简历要点。

### 3.4 AI 服务

- Provider 与 Model 分离；模型可在线获取或手动输入。
- 支持多个模型方案、独立 API Key、兼容协议与思考强度。
- API Key 使用浏览器加密保险库，不进入云端工作区。
- 自定义服务仅允许 HTTPS 公网地址，阻止本机和内网 SSRF。

### 3.5 账户与同步

- Identity Platform 提供邮箱/Google 登录、注册、验证、忘记密码和修改密码。
- 用户可修改昵称和头像。
- 浏览器记住最近登录账户的非敏感元数据，并支持快速切换或登录其他账户；不保存密码或令牌。
- 自动保存使用增量更新；用户可执行全量更新。
- 用户可创建还原点、查看最近还原点并回滚完整工作区。
- 同步错误提示可关闭；失败时保存按钮使用明确的断云图标。

## 4. 非功能需求

- 页面和重型功能按需加载；首屏不加载 PDF、富文本编辑器和非当前工作台。
- 桌面与移动端均可用，浅色/深色风格一致。
- 用户数据隔离；所有业务 API 需要已验证的 Identity token。
- XSS、危险 URL、上传文件和 Markdown/富文本必须经过过滤。
- 关键写操作可恢复；部署前必须通过类型检查、生产构建与关键路径浏览器检查。
